## Log de headers do webhook Emusys (v10, function version 28, ~19h20 BRT)

### Resultado do 1º dia (2 webhooks reais)

**Nenhum header custom** — só padrão HTTP + Cloudflare/AWS. Logo o `x-observador-token` (implementado
na v5) nunca vai receber valor: o Emusys não manda header próprio. Restam `?token=` na URL ou
allowlist de IP.

**`cf-connecting-ip = 52.67.146.71`** — e é **o mesmo IP** que o Hugo mostrou no `x-real-ip` do
caminho do n8n, atrás do Traefik. ⚠️ São **dois destinos distintos do mesmo remetente**: o Emusys
chama o n8n em `webhookla.latecnology.com.br` (Traefik) e o observador direto na Supabase

⇒ **Allowlist de IP passa a ser a melhor opção**: não depende de o Emusys alterar nada e não tem
segredo para vazar/rotacionar. Falta saber se o IP é estável — query e critério no item 15.
